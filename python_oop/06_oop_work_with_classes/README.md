# Робота з ООП - Класи та їх конструкції

## Тема
Програмування з використанням ООП. Робота з Класами та його основними конструкціями.

## Мета роботи
Навчитись працювати з Класами та його основними конструкціями: методами класу, статичними методами, properties, приватними атрибутами та магічними методами.

### Створений клас MyAnimals

Клас демонструє всі основні конструкції ООП:
- Конструктор `__init__`
- Звичайні методи (instance methods)
- Статичні методи `@staticmethod`
- Методи класу `@classmethod`
- Властивості `@property`
- Приватні атрибути (`_` та `__`)
- Магічні методи (`__str__`, `__repr__`, `__eq__`, `__hash__`)
- Арифметичні методи (`__add__`, `__sub__`, `__mul__`, `__gt__`, `__len__`)

## Висновок

### Що навчилися:

1. **Основи ООП**
   - Створення класів та об'єктів
   - Різниця між даними та об'єктами

2. **Типи методів**
   - Instance methods (звичайні методи)
   - Static methods (@staticmethod)
   - Class methods (@classmethod)

3. **Properties**
   - Контрольований доступ до атрибутів
   - Getter методи
   - Обчислювані властивості

4. **Інкапсуляція**
   - Приватні атрибути (_атрибут)
   - Сильно приватні атрибути (__атрибут)
   - Name mangling механізм

5. **Магічні методи**
   - Представлення об'єкта (__str__, __repr__)
   - Порівняння об'єктів (__eq__, __hash__)
   - Арифметичні операції (__add__, __sub__, __mul__)
   - Порівняння (__gt__, __lt__)
   - Інші методи (__len__)

6. **Class Variables**
   - Спільні дані для всіх об'єктів
   - Різниця між змінними класу та атрибутами об'єкта
