**Реалізовані OOP-парадигми:**

| Парадигма | Реалізація |
|-----------|-----------|
| Абстракція | Абстрактний клас `Shape` з методами `area()` та `perimeter()` (модуль `abc`) |
| Наслідування | `Rectangle`, `Triangle`, `Circle` успадковують `Shape` |
| Поліморфізм | `ShapeStorage.total_area()` викликає `area()` для кожної фігури |
| Інкапсуляція | Приватний атрибут `__shapes` у класі `ShapeStorage` |

**Ієрархія класів:**
```
Shape (ABC)
├── Rectangle  → area = width * height,   perimeter = 2*(width+height)
├── Triangle   → area = формула Герона,   perimeter = a + b + c
└── Circle     → area = π*r²,             perimeter = 2*π*r

ShapeStorage
├── __shapes: list[Shape]  (приватний)
├── add(shape)
└── total_area() → float  (поліморфізм)
```

**Інструмент агента:**
```python
def calculate_shape_area(shape: str, params: dict) -> dict:
    # rectangle → Rectangle(width, height)
    # triangle  → Triangle(a, b, c)
    # circle    → Circle(radius)
    return {"shape": ..., "area": ..., "perimeter": ...}
```

**Симуляція діалогу з AI-агентом (3 запитання):**

> **Запит 1:** Знайди площу та периметр прямокутника 10 на 4.
>
> **Агент:** Для прямокутника з шириною 10 і висотою 4:
> - **Площа** = ширина × висота = 10 × 4 = **40 кв. од.**
> - **Периметр** = 2 × (ширина + висота) = 2 × (10 + 4) = **28 од.**

> **Запит 2:** Обчисли площу трикутника зі сторонами 6, 8 і 10.
>
> **Агент:** Для трикутника зі сторонами 6, 8 і 10 (прямокутний трикутник):
> Використовую формулу Герона: s = (6+8+10)/2 = 12
> - **Площа** = √(12 × 6 × 4 × 2) = **24 кв. од.**
> - **Периметр** = 6 + 8 + 10 = **24 од.**

> **Запит 3:** Яка площа кола з радіусом 5?
>
> **Агент:** Для кола з радіусом 5:
> - **Площа** = π × r² = π × 25 ≈ **78.5398 кв. од.**
> - **Довжина кола** = 2 × π × r = 2 × π × 5 ≈ **31.4159 од.**
