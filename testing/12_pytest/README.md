# Звіт до роботи

## Тема: Тестування з бібліотекою pytest

### Мета роботи

Ознайомитися з бібліотекою `pytest`, навчитися створювати функціональні тести,
використовувати `pytest.raises`, параметризацію, fixtures, маркери та fixtures
із різними областями життя.

### Виконання роботи

Роботу виконано за матеріалами:

- [Завдання про pytest](https://github.com/BobasB/it_college/tree/main/notes/07_testing/02_pytest)
- [Зразок оформлення звітів](https://github.com/BobasB/it_college/tree/main/reports)

У файлі `app.py` реалізовано клас `Figure` з перевіркою типу фігури та додатної
довжини. У файлі `test_app.py` створено функціональні тести pytest:

- перевірку правильного типу трикутника;
- fixture `square`, яка створює квадрат із довжиною 10;
- параметризований тест для всіх дозволених фігур;
- параметризовані тести для неправильних типів і довжин;
- перевірку винятків через `pytest.raises`;
- два тести з fixture `allowed_figures` зі `scope="module"`;
- два тести з маркером `unit`.

Спочатку бібліотеку встановлено командою:

```bash
python -m pip install pytest
```

Основний запуск:

```bash
pytest -v
```

Запуск тестів із маркером:

```bash
pytest -m unit -v
```

Перевірка зібраних тестів:

```bash
pytest --collect-only
```

Під час демонстрації помилки один очікуваний результат було тимчасово змінено
на неправильний. Команда `pytest -x --tb=short` зупинила виконання на першому
проваленому тесті та показала назву тесту, очікуване значення й отримане
значення. Після повернення правильного очікування весь набір тестів знову став
успішним.

### Результати

```text
13 passed
```

Фактичний запуск із параметром `-v` підтверджує проходження всіх тестів.
Окремий запуск із `-m unit` виконує лише два тести, позначені маркером `unit`.

### Різниця між unittest та pytest

`unittest` організовує тести переважно у класах-нащадках `unittest.TestCase`,
використовує методи на кшталт `self.assertEqual` і має вбудовані методи життєвого
циклу `setUp` та `tearDown`. У pytest тести можна писати як звичайні функції,
перевірки виконуються через звичайний `assert`, а спільні дані зручно готувати
за допомогою fixtures. Pytest також надає просту параметризацію та маркери.

### Висновок

У роботі створено окремий приклад тестування з pytest. Реалізовано функціональні
тести, перевірку винятків, параметризацію, звичайну fixture, module-scoped
fixture та маркери. Мету роботи досягнуто: усі завдання виконано, помилковий
запуск перевірено, а фінальний набір тестів проходить успішно.
