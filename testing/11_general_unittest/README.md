#### 1. Перевірка даних

У класі `Figure` використано `assert` для перевірки типу фігури та додатної довжини:

```python
assert length > 0, "Довжина має бути більшою за 0!"
assert figure_type in self.FIGURES, "Невідомий тип фігури"
```

Для перевірки введеного імені використано `ValueError`:

```python
def create_name(name: str) -> str:
    if not name.strip():
        raise ValueError("Ім'я не може бути порожнім")
    return name.strip()
```

Правильне введення повертає очищене ім'я. Порожній рядок або рядок із пробілів викликає `ValueError`.

#### 2. Клас `Figure`

Реалізовано клас із підтримкою типів:

- `квадрат`;
- `прямокутник`;
- `трикутник`.

Додано властивості `get_figure_type`, `get_figure_length` та метод `get_angles`. Тести перевіряють правильні значення, невідомий тип, нульову та від'ємну довжину.

#### 3. Тестування функцій

Створено функцію `count_vowels`, яка рахує голосні літери в українському та англійському тексті. Перевірено:

- звичайний текст;
- порожній рядок;
- рядок із цифрами та спеціальними символами;
- українські літери;
- англійські літери.

Також протестовано `create_name` та `read_positive_number`.

#### 4. Життєвий цикл тесту

У `TestFigure` використано:

- `setUpClass` для спільного набору типів фігур;
- `setUp` для створення фігури перед кожним тестом;
- `tearDown` для очищення об'єкта після кожного тесту.

#### 5. `subTest`

`subTest` використано для перевірки всіх типів фігур і різних некоректних довжин. Це дозволяє побачити, який саме набір даних не пройшов.

#### 6. `unittest.mock`

Функція `read_positive_number` використовує `input()`. Щоб тест не вимагав ручного введення, застосовано:

```python
@patch("builtins.input", return_value="12.5")
```

Таким способом перевірено правильне введення числа та помилку для нульового значення. Додатково перевірено, що `input` викликався один раз.

Під час першого запуску було виявлено дві помилки: у наборі голосних не враховувалися англійські літери, а очікувана кількість голосних у слові `Україна` була вказана неправильно. Після виправлення реалізації та тесту повторний запуск завершився успішно.
