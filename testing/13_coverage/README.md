# Звіт до роботи

## Тема: Покриття коду в Python

### Мета роботи

Навчитися вимірювати покриття коду тестами за допомогою `coverage.py` та
`pytest-cov`, аналізувати пропущені рядки й розгалуження, створювати HTML-звіт
і перевіряти мінімальний поріг покриття.

### Виконання роботи

Роботу виконано за матеріалами:

- [Завдання про покриття коду](https://github.com/BobasB/it_college/tree/main/notes/07_testing/03_coverage)
- [Зразок оформлення звітів](https://github.com/BobasB/it_college/tree/main/reports)

У файлі `app.py` створено клас `Figure`. Метод `get_angles` має окремі
розгалуження для квадрата, прямокутника та трикутника. У `test_app.py` додано
параметризовані тести для всіх трьох гілок, а також перевірки неправильного
типу фігури й некоректної довжини.

### Встановлення

```bash
python -m pip install coverage pytest pytest-cov
```

### Запуск тестів і coverage

```bash
pytest -v
coverage run -m pytest
coverage report -m
pytest --cov=app --cov-report=term-missing -v
pytest --cov=app --cov-fail-under=90
coverage html
```

### Результати

Повний запуск тестів:

```text
7 passed
```

Результат вимірювання покриття:

```text
Name     Stmts   Miss Branch BrPart  Cover   Missing
----------------------------------------------------
app.py      14      0      4       0   100%
----------------------------------------------------
TOTAL       14      0      4       0   100%
```

Перевірка порогу `--cov-fail-under=90` також завершується успішно. HTML-звіт
створюється у папці `htmlcov/`; це службовий каталог і він не додається до
репозиторію.

### Порівняння покриття до і після тестів гілок

До додавання тестів для всіх типів фігур було виконано лише тест трикутника.
У такому випадку гілки квадрата й прямокутника залишалися неперевіреними, що
видно у звіті `coverage report -m` як пропущені рядки та переходи. Після
додавання параметризованого тесту для квадрата, прямокутника та трикутника
coverage зріс до 100% для рядків і розгалужень.

### Покриття рядків і розгалужень

Покриття рядків показує, який відсоток рядків коду виконався під час тестів.
Покриття розгалужень додатково перевіряє переходи між варіантами умов. Рядок
може бути виконаний, але не всі його переходи можуть бути перевірені, тому
branch coverage краще показує повноту тестування умовної логіки.

### Висновок

У роботі підключено `coverage.py` і `pytest-cov`, налаштовано branch coverage,
створено консольний та HTML-звіт, а також перевірено мінімальний поріг у 90%.
Усі завдання виконано, всі 7 тестів пройшли успішно, а покриття коду досягло
100%. Отримано практичні навички пошуку непокритих рядків і розгалужень та
підтверджено, що високий відсоток покриття допомагає оцінити повноту тестів,
але не замінює перевірку якості самих сценаріїв.
